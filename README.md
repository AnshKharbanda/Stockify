# 📈 Stockify

Stockify is an AI-powered stock analysis platform that provides company insights, technical analysis, price forecasting, anomaly detection, and AI-generated investment reports. It combines financial data analysis with machine learning models to help users better understand stock performance.

---

## 🚀 Features

- 🔍 Search stocks by company name
- 🏢 View company information and profile
- 📈 Interactive historical stock price charts
- 📊 Technical analysis using RSI, MACD, SMA, EMA, and Bollinger Bands
- 🤖 30-day stock price forecasting using ARIMA
- 🚨 Anomaly detection using Isolation Forest
- 📝 AI-generated stock analysis reports using OpenAI
- 🌐 FastAPI backend with an interactive Streamlit frontend
